# Frontend (React + Vite)

Firebase Cloud Messaging ile gelen büyük USDT transferi uyarılarını anında gösterir. Kurulum ve genel bilgi için [ana README](../README.md) dosyasına bakın.

## Komutlar

| Komut | Açıklama |
|---|---|
| `npm run dev` | Geliştirme sunucusunu `http://localhost:5173` adresinde başlatır |
| `npm run build` | Tür kontrolü yapar ve `dist/` klasörüne derler |
| `npm test` | Birim testleri |
| `npm run lint` | Kod kontrolü (Oxlint) |

Ortam değişkenleri için [`.env.example`](.env.example) dosyasına bakın.
